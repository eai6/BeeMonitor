{% comment %} Crop viewer: a crop opens here, over the page, not in a new tab. ← / → step through the crops of the same strip, Esc or a click outside closes. Pixels are shown unsmoothed so the fine detail the crop actually holds is what you see. Any page can use it: a link marked data-crop inside an element marked data-crop-strip (its data-label names the strip; a crop's own data-label, when it has one, names that crop). Delegated, so strips added later open here too. Its keys are taken first, so a page's own ← / → wait until it is closed. {% endcomment %} {# Hidden with the .hidden class, not the hidden attribute: .flex would override the attribute. #}
