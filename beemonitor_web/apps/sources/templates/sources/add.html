AWS S3 Configuration

Security: Use least-privilege access

Do NOT use AmazonS3FullAccess. Create a dedicated IAM user with read-only access to your specific bucket.

Recommended IAM Policy for BeeMonitor

Create an IAM user in AWS Console, attach this custom policy, then use its Access Keys below.

Enter your bucket name to generate the policy:

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "BeeMonitorListBucket",
      "Effect": "Allow",
      "Action": ["s3:ListBucket"],
      "Resource": "arn:aws:s3:::"
    },
    {
      "Sid": "BeeMonitorReadObjects",
      "Effect": "Allow",
      "Action": ["s3:GetObject"],
      "Resource": "arn:aws:s3:::/*"
    }
  ]
}

Setup steps:

  1. Go to AWS IAM Console
  2. Create a new IAM user (e.g., beemonitor-reader)
  3. Attach the policy above (Policies → Create Policy → JSON tab)
  4. Create Access Keys for the user (Security Credentials → Create Access Key)
  5. Paste the Access Key ID and Secret below
