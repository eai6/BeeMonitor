Zero-touch enrollment

Bake an enrollment token into your SD image once, then every unit you flash self-registers on first boot — no per-device key to copy. The device appears here automatically; you just set its name, location, and coordinates.

{% if new_token %}

Copy this token now — it won't be shown again.

Put it on the SD card's config (one line in /etc/beemonitor/uploader.env):

BEEMONITOR_API_BASE={{ api_base }}
BEEMONITOR_ENROLL_TOKEN={{ new_token }}
BEEMONITOR_RECORD_DIR=/home/beemonitor/Desktop/cameraOutput/beeHotel

On first boot (no device key present), the unit enrolls itself, writes its own key, and starts recording. Re-flashing the same Pi re-binds to the same device.
