Flash the BeeMonitor golden image, drop an enrollment token onto the card from your browser, and every unit self-registers on first boot — no per-device key to copy, and it works from any laptop. The device appears on your Devices page automatically; you just set its name and location.

How to set up a card

  1. Download the BeeMonitor image. {% if image_url %} Download .img.xz — then flash it with Raspberry Pi Imager (choose Use custom image). {% else %} (no image published yet — see the build guide in hardware/provision/) {% endif %}
  2. Generate a token below, then click Choose SD card & write to drop it onto the flashed card (Chrome/Edge).
  3. Assemble the hardware, insert the card, power on. The unit enrolls itself and appears on your Devices page.

Write it straight to the SD card — no terminal needed (Chrome or Edge, desktop)

  1. Flash the BeeMonitor image to the card (Raspberry Pi Imager) and keep it plugged in.
  2. Click below and pick the card's bootfs drive.

Prefer to set it up by hand?

Drop a file named beemonitor.conf on the card's bootfs partition, or add these lines to /etc/beemonitor/uploader.env on the Pi:

BEEMONITOR_API_BASE={{ api_base }}
BEEMONITOR_ENROLL_TOKEN={{ new_token }}

On first boot (no device key present), the unit enrolls itself, writes its own key, and starts recording. Re-flashing the same Pi re-binds to the same device.
